# 🎮 樂活/家族旅行 RPG 冒險中心 (Lohas Care Family Travel Plan)

這是一個專為家庭/團體旅遊設計的 PWA 互動式 H5 應用程式，結合了 RPG 戰力升級、任務提交、自動地圖航線與照片採集功能。

## ✨ 核心特色
- **無後端解耦**：支援 CSV / Google Sheets 行程表一鍵匯入。
- **多人分享**：支援產生一鍵分享連結 (URL Hash) 與 JSON 存檔匯出。
- **IndexedDB 離線相簿**：大容量本機照片儲存，不佔用 LocalStorage。
- **真離線 PWA**：支援 Cache-First 離線快取與手動備援打卡。
- **動態地圖航線**：Leaflet + 二次貝修弧線導航軌跡。

## 🚀 快速開始
直接開啟 `index.html` 或透過 GitHub Pages / Vercel 部署網址即可使用。
